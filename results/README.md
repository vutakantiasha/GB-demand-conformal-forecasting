# Results

This directory contains the retained outputs from the locked real-data evaluation.

- `metrics/overall_metrics.csv` — point and interval metrics for the primary model variants.
- `metrics/slice_metrics.csv` — robustness slices by season, settlement-period band, weekday/weekend and demand regime.
- `metrics/conformal_sensitivity.csv` — 80/90/95% conformal sensitivity across adaptation settings.
- `metrics/distribution_shift.csv` — train-to-test shift diagnostics.
- `metrics/lightgbm_shap_importance.csv` — descriptive LightGBM feature importance.
- `bootstrap/mae_vs_seasonal_naive.csv` — paired day-block bootstrap comparisons.
- `error_analysis/top_error_days.csv` — compact locked summary of the largest daily errors. The larger row-level taxonomy is regenerated by the pipeline and is not versioned.
- `figures/` — compact SVG visual summaries derived from the locked CSV evidence for the public release. The runtime plotting pipeline generates PNG outputs during a full run.

These files are evidence outputs. They should not be edited manually to improve model performance or coverage.
