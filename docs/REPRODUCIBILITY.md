# Reproducibility Contract

## What is frozen

The public release freezes the research configuration, model families, feature set, chronological partitions, calibration protocol and evaluation definitions used for the reported experiment.

## Data provenance

`data/raw/source_manifest.json` records first-party NESO resource identifiers, download URLs, retrieval timestamps, file sizes and SHA-256 hashes. The large raw files themselves are not redistributed.

## Execution provenance

`reports/reproducibility_manifest.json` records the Python/runtime package versions and repository-relative output locations associated with the completed run. `reports/training_summary.json` records model-selection metadata and `reports/data_quality.json` records the prepared-data audit.

## Reproduction sequence

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
make doctor
make test
python scripts/validate_neso_metadata.py
gbdf full-run --config configs/project.yaml
```

Because NESO states that historic data can be retrospectively corrected, a later download can differ from the checksum of the archived research run. Such a difference should be treated as a new data version rather than silently substituted for the locked evidence.

## Determinism

The project seeds Python/NumPy in the orchestration process and PyTorch in the isolated TFT worker. The synthetic smoke pipeline is intended to test deterministic engineering behaviour. Full real-data equivalence can still be affected by library/runtime differences and upstream dataset revisions, which is why environment versions and source hashes are recorded.


## Public-release output policy

Large row-level prediction/calibration tables and the full error-taxonomy table are generated by the pipeline but are not versioned in the public repository. Compact locked metrics, figures, source checksums, model-selection summaries and evidence reports are retained so the reported findings remain auditable without duplicating reproducible data products.

## Path policy

Versioned manifests use repository-relative paths. This makes the evidence portable across operating systems and avoids embedding local usernames or workstation directories.

## Locked-test policy

The 2026 test period is used only for final evaluation. Results from the locked test must not be used to choose new features, hyperparameters, model families or calibration settings. A genuine implementation defect requires a documented fix and consistent rerun of all affected variants.
